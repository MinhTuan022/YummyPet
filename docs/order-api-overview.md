# Tài liệu Hướng dẫn API Đơn hàng YummyPet

Chào mừng bạn đến với tài liệu hướng dẫn API đơn hàng của hệ thống YummyPet. Tài liệu này cung cấp mọi thông tin cần thiết để làm việc với đơn hàng trong hệ thống YummyPet.

## Danh sách tài liệu

1. **[Tổng quan API đơn hàng](./order-api-comprehensive-guide.md)** - Hướng dẫn toàn diện về tất cả các API đơn hàng
   - Bao gồm tất cả các kịch bản đặt hàng cho khách hàng và khách vãng lai
   - Chi tiết request và response cho từng loại đơn hàng
   - Quy trình xử lý theo loại khách hàng và kênh bán hàng

2. **[Xử lý dịch vụ cho khách vãng lai](./xuly-dichvu-khach-vang-lai.md)** - Hướng dẫn chi tiết về quy trình xử lý dịch vụ cho khách vãng lai
   - API tạo đơn hàng dịch vụ cho khách vãng lai
   - Quy trình cập nhật trạng thái
   - Hướng dẫn mô tả thú cưng trong serviceNotes

3. **[Hướng dẫn dịch vụ khách vãng lai](./dichvu-khach-vang-lai-guide.md)** - Chi tiết về cách ghi nhận dịch vụ cho khách vãng lai
   - Đặc điểm của dịch vụ khách vãng lai
   - Cách nhập thông tin thú cưng trong serviceNotes
   - Lưu ý quan trọng khi xử lý dịch vụ khách vãng lai

4. **[Ước tính thời gian dịch vụ](./updated-service-time-estimation-guide.md)** - Hướng dẫn về cách ước tính thời gian hoàn thành dịch vụ
   - Sử dụng trường estimatedDuration
   - Tự động tính toán thời gian hoàn thành
   - Hiển thị thời gian còn lại cho khách hàng

5. **[Kiểm thử ước tính thời gian](./service-time-estimation-test.md)** - Hướng dẫn kiểm thử tính năng ước tính thời gian
   - Các kịch bản kiểm thử
   - Script kiểm thử mẫu
   - Kết quả mong đợi

6. **[Quy trình đặt hàng online](./quy-trinh-dat-hang-online.md)** - Mô tả chi tiết quy trình đặt hàng online
   - Luồng xử lý từ đặt hàng đến giao hàng
   - Xử lý các trường hợp đặc biệt
